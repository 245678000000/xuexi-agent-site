| 维度 | OpenAI | Anthropic (Claude) | Google Gemini |
|------|--------|--------------------|---------------|
| 官方入口 | [Agents 总览](https://developers.openai.com/api/docs/guides/agents) | [Tool use 原理](https://platform.claude.com/docs/en/agents-and-tools/tool-use/how-tool-use-works) · [Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview) | [Agents overview](https://ai.google.dev/gemini-api/docs/agents) |
| 核心说法 | Agent 能规划、用工具、与其他 agent 协作、跨步骤保持上下文；先选「运行时」 | 工具调用是契约：模型从不自己执行，只发出结构化请求；你的应用（或 Anthropic 服务器）执行 | Managed agent = 可配置的 agent harness；一次 API 调用拉起 Linux 沙箱，自主推理/跑代码/管文件/上网 |
| 托管路线 | **Agents API**（OpenAI 管 Codex harness） | **Claude Managed Agents**（管 harness + 沙箱） | **Managed agents**（Antigravity / Deep Research） |
| 自建路线 | **Agents SDK**（循环在你的应用里）或自己用 Responses API | Messages API + 自己驱动 agent loop | 自建框架（ADK、LangGraph 等）或 Antigravity SDK |
