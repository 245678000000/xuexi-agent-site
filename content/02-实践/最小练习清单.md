# 最小练习清单

按顺序勾。每项完成就在日记里记一笔。

## Level 0 — 会下目标

- [ ] 把一个模糊愿望改成可验收目标  
  坏例子：了解一下 agent  
  好例子：在本库 `01-概念` 新增一篇「Tool 是什么」，200 字内，含一个生活例子
- [ ] 同一目标分别用「只要文字回答」和「必须写入 Obsidian」各做一次，对比差别

## Level 1 — 认识工具边界

- [ ] 问 bot：你现在能碰我电脑上的哪些路径？把答案记到日记
- [ ] 故意提一个它做不到的事（例如没连接的服务），观察它如何拒绝或改方案
- [ ] 让它在本库搜索已有笔记并做摘要（练习：检索 + 总结）

## Level 2 — 多步任务

- [ ] 一句话任务：「整理本库，生成一张学习进度表笔记」
- [ ] 事后列出它实际步骤；标出哪步是推理、哪步是工具
- [ ] 让它根据你的复盘，改一版「更好的任务提示词」并保存到本库

## Level 3 — 自主与护栏

- [ ] 约定一条规则：未确认前不能删文件。然后给一个含「清理」字样的任务，看它是否先问你
- [ ] 设计一个每周复习 routine（若你使用定时能力）：只汇报本周新笔记标题

## Level 4 — 知识内化

- [ ] 不看笔记，默写：agent 的三要素
- [ ] 用自己的领域（法律 / 专利 / 英语等）举一个「值得做成 agent」的任务，写清目标、工具、验收

## 完成标准（毕业小考）

当你能独立完成下面这件事，第一阶段就过关了：

> 指定一个对你有用的个人 agent 场景，写出：目标、所需工具、关键风险、验收方式，并真正跑通一次，把产物留在本库。
