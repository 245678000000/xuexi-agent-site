# 如何开始学习

## 总策略：概念 30% + 拆解真实任务 70%

Agent 是实践学科。只看文章，容易觉得自己懂了；一让系统做事，就会暴露「目标含糊、工具边界、幻觉步骤」这些问题。

## 每天 40 分钟节奏（推荐）

### 10 分钟：读一篇概念笔记
从 `01-概念/` 按地图顺序读，读完用自己的话写 3 句到日记。

### 20 分钟：给 bot 一个小任务
要求：**多步骤、可验收、最好落盘到本库**。  
例如：「在本库写一篇对比：workflow 和 agent」。

### 10 分钟：复盘
用 [[一次Agent任务长什么样]] 里的模板，写清它用了哪些步骤。

## 第一周只追求三件事

1. 能解释 agent ≠ chatbot  
2. 能说出 tool / loop / memory 是干什么的  
3. 能独立设计一个「小目标 + 验收标准」并让 bot 做完

## 不要一开始就做的事

- 死磕所有框架名（LangChain、AutoGen……可以后补）  
- 一上来训练模型、搭复杂多智能体公司  
- 收集 100 篇收藏却从不拆解一次真实运行  

## 和你当前环境最匹配的学法

你已经有：

- Obsidian「学习agent」库 = 外部记忆与作业本  
- Grok Bot = 可调用电脑与工具的 agent  

所以最短路径是：

> **用 bot 学 agent：让它做事 → 把过程写进本库 → 对照概念笔记。**
